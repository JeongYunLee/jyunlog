# JeongYun Lee CV (Nuxt 3)

Single-page bilingual CV website built with Nuxt 3 and TailwindCSS.

## Features

- Single route CV page (`/`)
- Korean/English language switch
- Print-friendly stylesheet (`@media print`)
- Legacy routes redirected to `/`

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run start
```

## SEO

- Canonical base URL: `https://jyunlee.com`
- `robots.txt` and `sitemap.xml` aligned to the same domain
